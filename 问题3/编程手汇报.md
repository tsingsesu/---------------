## 四、S6 适用边界的明确判断（供论文直接引用）

1. **结论成立的预报精度范围（按白天 RMSE）**：调整收益为正要求
   **白天 RMSE ≲ 12% 白天实际出力**；12–14% 为临界带；**≳14% 时调整失效（主动损害，最大实测
   −79 万元/年）**。真实数据口径为 7.50%（357.3 kW），处于"充分成立"区。
2. **按信息量（λ 阻尼）**：只要 τ≥6 的更新相对 0:00 预报有**任何**正信息量（λ>~0.001），
   调整即正收益，收益随 λ 近线性；λ=0（更新不含信息）时收益为 −9 217 元（数值零附近的小负值），
   说明"没有新信息就不要调整"。
3. **纯噪声（更新=0:00 预报+独立噪声）**：调整收益 **−326.4 万元/年**——基于噪声的调整是
   主动损害，工程上必须以"更新确实包含新信息"为前提。
4. **故意低报的最优门槛（理论）**：单时段分析给出最优计划分位 F(x*) = (κ₊−1)/(κ₊+κ₋−1)；
   题目参数 (0.5,1.5) 下 = 0.50（中位数锚定，不主动低报）；**只有 κ₊−κ₋ > 1 时**（如 κ₊=2.0）
   低报才成为期望最优。数值验证（20 万样本）与理论分位逐位一致。

## 七、假设与风险

1. **预报分解的时点选择（D-07 已裁决，实施细节需写进论文）**：τ 时刻发布后，其覆盖的整点
   结点取"τ′ ≤ τ 的最新发布"的预报（例：6:00 时刻的 1:00–6:00 结点仍用 0:00 发布的预报，
   7:00 及以后的结点用 6:00 发布的预报）。这保证每个决策时刻只使用当时已发布的信息
   （信息集 F_τ 单调增大），是本问"多阶段决策"语义的精确实施。
2. **偏差结算基准 = 0:00 计划 x（每个阶段都是）**：D-12 的结算发生在"计划 x 与最终 y"之间，
   中间阶段的改值若被后续阶段改回则不产生费用；故所有调整阶段相对 x 优化偏差。若改用
   "相对上一阶段值"作基准，会把"改回"误记为超用/欠取（与 D-12 不符）。该点已与构思手确认。
3. **"前瞻偏差"选项**：主模型每个阶段都把偏差项放进目标（计划的锚定效应被优化器自动权衡：
   计划越可能被下调、其边际成本越低）。保留"0:00 阶段不含偏差项"的口径开关（分析对照），
   本次未启用——主口径与 D-12/D-13 一致，且退化一致性验证通过。
4. **`调整购电量` 表的"全天购电费"列**：两表列标签相同（模板如此），口径不同——计划表 =
   计划购电费 Σp·x；调整表 = 当日总费用（计划+调整+紧急，D-12）。该差异在表注与论文中说明。
5. **可追溯口径为"极端"对照**：每天 18:00 用当日最后预报重优化全天（含已执行段），费用
   13 798 848 元（比不可追溯低 0.125%）——这是规则收紧程度的上界对照，不代表题目允许。
6. **S4b/MATLAB 复算只覆盖 3.20 单日**：选它因为它是四个指定日期中缺额最大、阶段最多的一天；
   全年链的逐位一致由 verify_q3 的独立重算路径保证（同 Python 内核不同调用路径）。
7. **随机规划部分的"完全追索"口径**：第二部分 SAA 的第二阶段假定情景揭示后全天重优化——
   这是经典两阶段的定义（用于检验计划对分布的稳健性），与主模型的多阶段（预报受限）口径
   不同层次，报告中已显式标注；第一部分（情景模拟）则完整重跑多阶段链，与主模型同口径。
